# Stroid

بيئة تطوير لأندرويد تعمل أوفلاين.

- المرحلة 1: المحرر (Monaco) وإدارة الملفات
- المرحلة 2: Terminal وبيئة Debian (عبر proot) مع Python وNode وgit، وزر تشغيل الملف

## البناء
شغّل `build-apk` من تبويب Actions ونزّل `stroid-debug-apk`.
أول تشغيل للتطبيق يفك بيئة Linux (دقيقة تقريبًا) ثم تعمل بدون إنترنت.
