# Stroid

بيئة تطوير لأندرويد تعمل أوفلاين. المرحلة 1: المحرر (Monaco) وإدارة الملفات.

## البناء
1. ارفع المشروع إلى GitHub.
2. افتح تبويب Actions وشغّل `build-apk`.
3. نزّل `stroid-debug-apk` من نتيجة التشغيل وثبّته على الجوال.

محرر Monaco ينزّل ويُضمَّن في الـ APK وقت البناء، ولا يحتاج التطبيق إنترنت بعد التثبيت.

## المراحل القادمة
2. Terminal وبيئة Linux (proot)  3. اللغات ومتجرها  4. دعم الذكاء الاصطناعي
